# omis107hw3
hw3 for omis107

Part 1 — one feature, one pull request (everyone)
do it by Tuesday night

Add one feature of your choice to the project, on your own branch, and open a pull request. The feature must be visible from the main page. The PR description says what the feature is and how to try it.

Do not merge your own pull request. It will be merged after your reviewer approves it (Part 2).

There may be conflicts for the second and third pull requests, because all three features touch the main page. Inability to resolve conflicts won't be counted negatively for the grade. Just take it as an opportunity to learn. 

 
Part 2 — one review (everyone)
do it by Thursday at 10:19 am

A reviews B's pull request, B reviews C's, C reviews A's.

To review: get the teammate's branch on your laptop, run the project, and check that the feature works and that nothing else broke. Leave at least one comment on the pull request, then either approve it or request changes.

If changes are requested on your own pull request, fix them on the same branch, push, and ask your reviewer to look again. Once your pull request is approved, merge it.
